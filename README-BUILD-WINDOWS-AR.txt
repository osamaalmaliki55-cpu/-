خطوات بناء ملف EXE على Windows عبر GitHub Actions

1) أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد إليه (المجلد .github مهم).
2) افتح تبويب Actions في المستودع.
3) اختر Build Windows installer ثم Run workflow.
4) انتظر انتهاء البناء بنجاح.
5) افتح نتيجة التشغيل (Run) ثم قسم Artifacts ونزّل Daftar-Accounts-Windows-Installer.zip.
6) فك ضغط الملف لتحصل على ملف Setup بصيغة EXE.

تنبيهات مهمة:
- هذه الحزمة ما زالت مصدرًا للبناء وليست ملف EXE جاهزًا.
- يجب اختبار تسجيل الدخول ومزامنة Firebase على Windows، وقد يحتاج Google Auth إلى إعداد localhost ضمن Authorized domains.
- تسجيل الدخول والمزامنة يحتاجان الإنترنت. واجهة البرنامج وبياناته المحلية قد تعمل دون إنترنت، لكن لا تعتبر النسخة مستقلة تمامًا قبل اختبارها دون اتصال؛ مكتبات Firebase تُحمّل حاليًا من الإنترنت.
- بيانات التطبيق المحلي منفصلة عن Chrome. صدّر JSON من الموقع واستعده داخل التطبيق بعد تثبيته.
- لا تحذف نسخة الموقع أو نسخة JSON الاحتياطية.
