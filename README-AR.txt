دفتر الإيرادات والمصروفات - نسخة سطح المكتب
المصمم: osama almaliki

مهم:
- الملف index.html هو نسخة من الملف الذي رفعه المستخدم، ولم تُحذف منه سجلات أو تُعدّل إعدادات Firebase.
- هذا مجلد مصدر للتجهيز والبناء، وليس ملف تثبيت EXE جاهزًا بعد.
- التطبيق يستخدم تخزين المتصفح المحلي داخل ملف تعريف Electron، وهذا منفصل عن تخزين Chrome للموقع؛ لذلك لا تظهر بيانات Chrome تلقائيًا داخل التطبيق. قبل الاعتماد عليه يجب استيراد نسخة JSON الاحتياطية من داخل البرنامج.
- الاستخدام دون إنترنت يتيح الواجهة والبيانات المحلية بعد تثبيت التطبيق، لكن تسجيل الدخول والمزامنة السحابية يحتاجان إلى الإنترنت. مكتبات Firebase الحالية تُحمّل من الإنترنت، لذلك يلزم اختبار الوظائف دون اتصال وإتاحة المكتبات محليًا قبل اعتبار النسخة مستقلة بالكامل.

للبناء على Windows:
1) ثبّت Node.js LTS على جهاز البناء.
2) افتح موجه الأوامر داخل هذا المجلد.
3) نفّذ: npm install
4) نفّذ: npm run dist:win
5) ملف التثبيت سيظهر داخل مجلد release.

لا تحذف نسخة الموقع أو بيانات المتصفح الأصلية. صدّر نسخة احتياطية JSON من البرنامج قبل تجربة النسخة المكتبية، ثم استخدم زر «استعادة نسخة احتياطية» داخل التطبيق لاستيرادها.
